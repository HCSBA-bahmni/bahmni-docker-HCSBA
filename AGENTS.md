# QA HIS HCSBA

Para preparar, ejecutar o documentar QA de esta migración y sus entregas, leer y aplicar [his-qa-release](skills/his-qa-release/SKILL.md) y sus referencias. Aplicar también `bahmni-nextjs-migration` y las instrucciones locales del entorno cuando corresponda.

La fuente de la skill, la pauta, el catálogo y el harness viven en `bahmni-nextjs-hcsba`; este repositorio distribuye el paquete en `skills/his-qa-release`. Seguir la [guía para contribuyentes](skills/his-qa-release/references/contributors.md). El harness registra y evalúa resultados; no ejecuta pruebas ni despliega. Conservar evidencias y datos de ensayo fuera de Git y no acreditar `.225` con pruebas simuladas o locales.
